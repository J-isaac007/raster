# Privacy policy

Raster is a desktop app that runs entirely on your computer. It has no
accounts, no analytics and no telemetry.

## Your art and files

Your sprites, palettes and exports stay on your computer. Raster reads and
writes only the files you open, save or export, plus its own settings and
autosave in `%APPDATA%\Raster`. Nothing you draw is uploaded anywhere.

## Update check

The installed version of Raster (`Raster-Setup-<version>.exe`) checks for new
versions:

- **When:** when Raster starts, and when you choose **Help › Check for
  Updates**.
- **Where:** it asks GitHub (`github.com`, and GitHub's download servers) for
  the latest release of [J-isaac007/raster](https://github.com/J-isaac007/raster/releases).
  If there is a newer version, it downloads the installer from there.
- **What is sent:** a standard web request for the release information. Like
  any web request it includes your IP address, and it identifies the
  app and its version. No personal information, files or usage data are sent.
- **Who receives it:** GitHub, under the
  [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  The Raster maintainers don't receive or see these requests.

**To turn it off:** open **Help › About Raster** and clear **Check for updates
when Raster starts**. Raster then makes no network connections unless you
choose **Help › Check for Updates**.

The portable version (`Raster-<version>-portable.exe`) never checks for
updates and never connects to the network.

## Links

Links in the app (such as the install guide) open in your web browser only
when you click them.
