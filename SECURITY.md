# Security Policy

Raster runs entirely in your browser. It has no server, accounts or telemetry,
and your files never leave your machine unless you save or export them.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository instead. We aim to reply within a week.

Things we especially want to hear about: crafted `.raster`, image or palette
files that crash the editor, hang it, or run code.
